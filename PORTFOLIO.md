- **AWS CDK in TypeScript:** infrastructure as code in the same language as the app.
- **Web app instead of a native app:** recruiters open links; mobile skills are shown through Tsebo.
- **Terminal UI plus normal navigation:** fun for those who explore, clear for those who don't.
